# FUMI FUMI MOGURA

床へ常時投影し、Webカメラで足を認識して遊ぶモグラたたきゲームです。ゲーム中の入力はカメラだけを使います。

![ゲーム方式](https://img.shields.io/badge/INPUT-CAMERA%20ONLY-59f3d5)
![画面](https://img.shields.io/badge/DISPLAY-16%3A9%20PROJECTOR-ff9f1c)

## できること

- 3列×3段の9穴を使う、1人用の床投影レイアウト
- ページを開くと自動開始し、時間制限や終了画面なしで動き続ける常設投影モード
- 投影画面は土・穴・モグラ・認識した足だけを表示し、枠や操作説明は表示しない
- 出てきたモグラをカメラで認識した足で踏む
- カメラ映像上の4点を指定し、斜めからの映像を投影座標へ補正
- 別ウィンドウの専用操作画面で、カメラ映像・補正枠・足の認識状態を確認して各設定を操作

## まず動かす

Node.js 20以降を使います。

```bash
npm install
npm run dev
```

Chromeで表示された `http://localhost:5173` を開きます。カメラは `localhost` またはHTTPSでのみ使えます。

確認コマンド:

```bash
npm test
npm run build
```

## カメラの準備

1. ページを開き、Chromeのカメラ使用を許可します。
2. `Esc` を押して設定を開き、カメラ画角を確認します。
3. カメラを斜め前方へ固定し、プレイヤー1人の全身と床の投影範囲を映します。
4. 「4点調整をやり直す」を押します。
5. カメラ映像上で、投影範囲の **左上 → 右上 → 右下 → 左下** を順にクリックします。
6. 「専用操作画面」を押して別ウィンドウを開き、左右の足に黄色い `L` / `R` が出ることを確認します。

MediaPipe Pose Landmarkerで、かかと・つま先の位置を4点射影変換しています。映像と姿勢推定はブラウザ内だけで処理し、保存・送信しません。

## 操作

| 入力 | 操作 |
|---|---|
| カメラで認識した足 | モグラをたたく |
| `Esc` | 設定を開く・閉じる |
| 設定内の「音」 | 音のON/OFF |
| 設定内の「全画面」 | 全画面表示 |
| 設定内の「専用操作画面」 | カメラ確認と設定操作を別ウィンドウで表示 |

マウス、タッチ、ゲーム用キー、LiDAR、TouchDesigner、WebSocketからはゲームを操作できません。カメラ許可、4点調整、音、全画面などの運営操作だけ画面ボタンを使います。

## 投影時の推奨

- 解像度: 1920×1080、16:9、Chrome全画面
- 投影範囲の目安: 横3.2m × 奥行1.8m
- 外周に50cm以上の余白を取り、壁・机・機材から1m以上離す
- 滑りにくい無地の床を使い、ケーブルを床用カバーで固定する
- 1人ずつ、走らず・ジャンプせず・軽く踏んで遊ぶ

## 構成

```text
src/game-core.js           ゲーム進行・得点・出現制御
src/foot-zone-detector.js  足の進入・退出と連打防止
src/homography.js          カメラ4点補正
src/camera-foot-tracker.js MediaPipe足認識
src/audio.js               Web Audio効果音
src/main.js                画面とカメラ入力の統合
src/monitor.js             別画面の認識モニター
src/assets/soil-texture.png 実写調の土テクスチャ
src/assets/mole-character.png 3Dモグラ素材
```

`main` ブランチへのpushで、GitHub Actionsがテスト・ビルドを行いGitHub Pagesへ公開します。
